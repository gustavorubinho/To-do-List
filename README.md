# 📓 To-do-List

Um aplicativo simples e intuitivo para organizar tarefas do dia a dia, permitindo adicionar, concluir e remover tarefas de forma rápida e prática.

## 🚀 Funcionalidades

* 🔔 Agendar lembretes
* 💾 Organização simples e intuitiva
* 📱 Interface responsiva

## 🛠️ Tecnologias utilizadas

* **HTML5** — Estrutura da aplicação
* **CSS3** — Estilização e responsividade
* **JavaScript** — Lógica e interatividade

## 📂 Estrutura do projeto

```text
to-do-list/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🎯 Objetivo

Eu assisti homem de ferro semana passada, e percebi que ter um tipo de Jarvis assistente que te lembra de tarefas não é uma ideia ruim. Então fiz esse projeto com objetivo criar um assistente Jarvis, que te lembra de realizar tarefas e te ajuda a não esquecer dos seus compromissos. Conceitos fundamentais de desenvolvimento web, principalmente **HTML, CSS e JavaScript**.
